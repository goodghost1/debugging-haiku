One haiku about debugging, written for the
[Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
bounty on make.fun. `main.ts` writes the haiku to `/output/entry.txt`.

```
cursor blinks at three
the red log line will not change
and the bug was me
```

Three lines, 5-7-5 syllables, 74 characters.
